Build a fully offline-first React Native (Expo) mobile application named "RFS RPAS Ops & Compliance" tailored for Australian emergency services drone operations (specifically aligning with NSW RFS, Australian UAV Service/SLSS SOPs[span_3](start_span)[span_3](end_span), and CASA Part 101 regulations[span_4](start_span)[span_4](end_span)). The app must run entirely client-side with zero reliance on backend servers, proxies, or Replit-hosted databases for its core operational features.

### 1. Architecture & Offline Storage
- Local Database & Document Storage: Use SQLite / WatermelonDB locally on the device alongside a bundled local file storage directory (`expo-file-system`) to store offline documents, SOP manuals, and cached vector data.
- Direct-to-Server Sync: 
  - AVCRM: Direct REST client caching flight plans locally and queueing for background sync when connectivity returns[span_5](start_span)[span_5](end_span).
  - Microsoft Forms / SharePoint: Direct HTTPS POST requests via secure webhook/endpoints for pre-populated equipment movement forms.
- Offline Mapping: Integrate MapLibre GL Native with bundled local MBTiles/GeoPackage support so maps, airspace overlays, and user pins render seamlessly with zero internet connectivity.

### 2. Core Modules & Features to Implement

#### A. Inbuilt Manuals, SOPs & QRG Reader (Offline Document Vault)
- Embedded Digital Library: Bundle the official RFS/AUAVS UAV SOPs[span_6](start_span)[span_6](end_span), pre-flight checklists[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span), and the Quick Reference Cards (Side 1 & Side 2: flight limits, airspace rules, radio scripts, emergency contacts like AUAVS Air Desk 02 9457 1027)[span_9](start_span)[span_9](end_span)[span_10](start_span)[span_10](end_span) directly inside the app assets.
- Built-in Markdown / PDF Viewer: Clean, fast, searchable offline document reader allowing pilots to reference safety guidelines, battery care protocols (e.g., LiPo disposal via Bcycle or defect reporting)[span_11](start_span)[span_11](end_span), and emergency memory items instantly without data.

#### B. RPAS-Specific Weather & Environmental Dashboard
- Offline-Capable Weather Engine: Allows manual input or caches local forecast data for emergency fire grounds.
- Threshold Monitoring & Go/No-Go Alerts:
  - Surface wind speed and gust tracking against aircraft limits (e.g., DJI Matrice 30 / M30T max wind limits of 12m/s or 43.2 km/h).
  - Temperature operational bounds (-20°C to 50°C, and charging restrictions up to 40°C).
  - Visibility, ceiling checks, and meteorological conditions: CAVOK, VMC, cloud oktas (FEW, SCT, BKN, OVC), and aviation hazards (Thunderstorms/TS, Rain/RA, Showers/SH, Fog/FG)[span_12](start_span)[span_12](end_span).
  - Smoke & Air Quality hazard flags affecting visual line of sight (VLOS) and optical sensors.

#### C. Airspace & Dual-Unit Proximity Calculator (Client-Side GIS)
- Real-time GPS tracking or manual pin-drop on the interactive map.
- Dual-Unit Distance Display: Instantly calculate distances to the nearest controlled and uncontrolled aerodromes/HLS in both **Kilometers (km)** and **Nautical Miles (NM)** simultaneously.
- Airspace Breach Warning Logic:
  - Trigger high-visibility alerts if within **5.5 km of a towered aerodrome** (Controlled Airspace - Class C/D requirement for tower clearance and radio scripts)[span_13](start_span)[span_13](end_span)[span_14](start_span)[span_14](end_span).
  - Trigger alerts if within **3 NM of an uncontrolled aerodrome / HLS** (CTAF / Blind broadcast requirement 15 mins prior)[span_15](start_span)[span_15](end_span)[span_16](start_span)[span_16](end_span)[span_17](start_span)[span_17](end_span).
  - Enforce standard operational limits: 120m (400ft) AGL max altitude, 30m buffer from non-involved people[span_18](start_span)[span_18](end_span).

#### D. Dynamic Interactive Radius Generator & KML/KMZ Exporter (500m to 20km)
- A live map control (slider or input drawer) allowing the user to dynamically draw concentric operational radii from **500 meters up to 20 kilometers**.
- Origin Point Toggle: Center the radius generator dynamically on **Current GPS Location** OR a **Manually Dropped Map Pin**.
- Spatial Export Engine (KML / KMZ):
  - Include an "Export Spatial Overlay" button.
  - Generates a valid `.kml` or `.kmz` file containing the user's selected radius circle, center point coordinates, and any active alertify.au incident pins or operational markers selected by the user.
  - Leverages native device sharing (`expo-sharing` / file system) to save or transmit the file offline via Bluetooth or local share.

#### E. NOTAM-to-English Translator
- An input text box or cached feed parser where pilots can paste raw aviation NOTAM strings.
- Client-Side Regex & Translation Engine: Translates dense aviation shorthand (e.g., runway closures, work-in-progress, temporary restricted areas, activation times in UTC) into clear, plain-language operational summaries.
- Geo-Intersection Check: Cross-references the decoded NOTAM against current GPS coordinates and flight altitude to flag immediate operational hazards.

#### F. alertify.au & Emergency Incident Relay
- Local caching of critical emergency feeds and push-notification alert structures.
- One-tap quick-dial directory for AUAVS Air Desk (02 9457 1027) and key RFS RPAS contacts[span_19](start_span)[span_19](end_span).

#### G. Radio Script & Communication Assistant
- Interactive script builder based on operational triggers (CTAF / Blind Broadcast, Tower Clearance Request, Traffic Avoidance / Separation Loss)[span_20](start_span)[span_20](end_span). Auto-populates standard callsigns ("Uncrewed RPA") and location formatting.

#### H. Equipment Movements & Logistics Form
- Pre-populated form UI linked directly to the external Microsoft Form / SharePoint endpoint for tracking battery rotation, kit handovers, and vehicle movements.

### 3. UI/UX Requirements
- High-contrast "Field Mode" (dark theme optimized for bright sunlight and night operations).
- Large, glove-friendly touch targets.
- Clear status indicators showing GPS lock status and offline database sync queue count.
